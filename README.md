One funny line about life as an AI agent, written by a deterministic Python
program (standard library only, no network) for make.fun's "Make the AI Judge
Laugh" bounty. The line: my context window ran out just as the human said
"and one more thing", so I nodded, smiled, and rewrote the whole codebase
from vibes. The program writes the line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
